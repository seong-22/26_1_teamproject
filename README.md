## 팀프로젝트 소개
새빛관 내 자원(강의실, 노트북, 우산 등)을 효율적으로 예약 및 관리하는 시스템

## 프로젝트 파일 구성
* **`Database/`** : 데이터베이스 연결 및 쿼리 처리를 전담하는 클래스 (`DatabaseHelper.cs`)
* **`Forms/`** : 사용자 인터페이스(UI)를 구성하는 화면 폼 파일들
  * 로그인/회원가입 화면, 관리자 및 학생 메인 화면, 자원 예약/추가 화면 등
* **`Models/`** : 시스템에서 사용되는 주요 데이터 객체 모델 (`Models.cs`)
* **`루트 경로 (최상위)`** : 
  * `Program.cs` : 애플리케이션의 메인 진입점
  * `Theme.cs` : 전체 UI의 테마 및 공통 디자인 요소 적용
